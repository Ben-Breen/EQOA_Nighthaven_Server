## What stayed the same, and what changed

N01 and the latest N02 share the inspected ISO, PCSX2 executable, ROM BIOS and BIOS-sidecar input hashes and the same boot arguments. Recorded emulator-setting overlays match except session-specific log/snapshot paths. DNS proofs show the same installed DNS executable hash, TAP binding and deny-recursion policy.

Card contents and guest network-profile preparation differ. The operator used the **Frontiers in-game network configuration tool during N02** to set the intended DNS. The host had also received networking updates/rebooted, runner/helper versions and full INI fingerprints differ, and the time policy changed. N01 uses its earlier bounded observation; N02 has a 300-second limit from launch and no DHCP-based cutoff. This is a useful bounded comparison, **not a single-variable causal experiment**. In particular, do not infer that the card alone caused the resolver change or that an emulator observation is original-hardware behavior.

The earlier N02 control recorded four PTR questions to `192.18.0.1`, three to the lab resolver, three REFUSED replies and no DNAS-associated A question within its shorter window. Manual setup overlapped its first-DHCP timer. The latest run replaces neither that evidence nor its limitations; it provides a corrected-address observation with a different time policy.
